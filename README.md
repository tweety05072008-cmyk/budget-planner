# 女大一生財務規劃與記帳分析系統 🌸

專為女大一生設計的個人收支分配與互動預算模型，透過視覺化環形圖與金流分流原則，建立良好的個人理財與資產累積習慣。

## ✨ 特色亮點

- **互動式環形圖 (Donut Chart)**：清楚掌握 $15,000 可支配餘額的比例分配。
- **金流三層分流**：固定房租 $14,000 + 自由支配 $15,000，專款專用。
- **資產累積引擎**：每月定期定額 ETF ($2,000) ＋ 高利活存緊急備用金 ($2,000)，大學四年預計累積約 19.2 萬本金。
- **女大生實用建議**：膠囊衣櫥治裝原則、日常飲食控管與安全指標健檢。
